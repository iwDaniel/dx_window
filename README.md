# DX_WINDOW
### Main
DX_WINDOW是适用于gm8.1(2)的一个窗口管理库,目前具有以下功能:
1. 创建和管理多个窗口;
2. 支持窗口的关闭操作;
3. 支持窗口的移动，调整大小等操作;
4. 为了我制作的引擎，有一个可以显示询问框的接口，返回是一个布尔值，表示用户是否点击了确定按钮;
